Troubleshoot

Troubleshooting

Common fixes for frequent issues

QUIC connection timeout

Some networks block UDP/443. Fix: set --protocol http2 to fall back to HTTP/2, or check your firewall rules.

fake-IP conflict

The fake-IP mode in Clash and similar proxies may hijack Cloudflare DNS. Fix: add trycloudflare.com to your direct-connection rules.

Error 1033

Cloudflare Argo Tunnel error, usually caused by a mismatched tunnel configuration. Fix:cftunnel down then run cftunnel up，or delete and recreate the tunnel.

Error 530

DNS points to the wrong tunnel. Fix: verify that the DNS CNAME targets the correct tunnel UUID, then use cftunnel remove to clean it up and add it again.
